เพิ่มหมวด “นำเสนอ” ในเมนูตั้งค่า
- เปิด/ปิดหมวดนำเสนอได้
- เปิด/ปิดการเชื่อมโยงกับสไลด์อัตโนมัติได้
- แก้ไขชื่อการประชุม / หน่วย / ครั้งที่ / วันเวลา / สถานที่
- แก้ไขระเบียบวาระ 1–4
- แก้ไขหัวข้อนำเสนอผลงาน
- แก้ไขรายชื่อหน่วย/ผู้รับผิดชอบที่นำเสนอ
- แก้ไขระเบียบวาระ 6–7
- กำหนดเลขสไลด์ที่เป็น “นำเสนอผลงาน” ได้
- เมื่อเปลี่ยนสไลด์ การ์ด “นำเสนอ” เปลี่ยนหัวข้อให้ตรงกับหน้าปัจจุบัน
- ในสไลด์นำเสนอผลงาน จะแสดงหน่วย/ผู้รับผิดชอบทั้งหมด
- รีเซ็ตกลับเป็นข้อมูลจาก PowerPoint ที่แนบได้
